description: Automatically expand a brief task into a comprehensive, expert-level implementation plan (Role, Goal, Context, Constraints, and recommendations).
---

1. **Analyze Input**: Take the user's brief task description.
2. **Assign Persona**: Identify the expert role (Senior Flutter Dev, Oracle PL/SQL Architect, React/UI Designer, etc.) based on the content.
3. **Generate Implementation Plan**: Create or update `implementation_plan.md` with:
   - **Role**: Define the expert persona.
   - **Goal**: Clear, actionable objective.
   - **Technical Context**: Deep dive into the relevant files and architecture.
   - **Critical Recommendations**: Best practices, performance tips, and UI/UX enhancements.
   - **Step-by-Step Execution**: Granular tasks.
4. **User Review**: Present the plan for approval before any code execution.
